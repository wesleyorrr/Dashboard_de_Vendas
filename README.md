# 📊 DashBorg - Relatório de Vendas (Power BI)

Este projeto apresenta um **dashboard interativo de vendas** desenvolvido com **Power BI**, focado na análise de **lucros e desempenho por país**.

O objetivo é fornecer **insights claros e visuais** para auxiliar na tomada de decisões estratégicas baseadas em dados reais de vendas.

---

## ✨ Funcionalidades

- Visualização de lucros por país 🌍  
- Comparativo de desempenho entre regiões  
- Gráficos dinâmicos e filtros interativos  
- Destaques para países com maior e menor rentabilidade  
- Interface limpa, responsiva e de fácil interpretação

---

## 🛠️ Tecnologias e Ferramentas

- **Power BI Desktop**  
- **DAX (Data Analysis Expressions)**  
- **Modelagem de Dados**  
- **Visualizações interativas**  
- **Transformações com Power Query**

---

## 📁 Estrutura dos Dados

O relatório considera os seguintes campos principais:

- Nome do país  
- Receita total  
- Custo total  
- Lucro líquido  
- Volume de vendas  
- Período (ano/mês)
